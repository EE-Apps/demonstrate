Актуальность проекта

  • ❌ Стандартные калькуляторы не умеют строить графики и решать уравнения
  • ❌ Нет удобных конвертеров с поддержкой рубля ПМР (PRB)
  • ❌ Приходится использовать 3–4 разных приложения для одной задачи
  • ✅ Этот проект объединяет всё в одном месте
  • ✅ Работает на телефоне, компьютере и в браузере

Цель

Создать удобный калькулятор для учёбы, который работает на Windows, Linux и Android без изменения кода.

Область применения

  • Школьные занятия по математике
  • Домашние задания и самопроверка
  • Подготовка к экзаменам
  • Повседневные вычисления

Задачи

  1. Проанализировать аналоги
  2. Разработать единое веб-ядро
  3. Реализовать калькулятор, уравнения, конвертеры
  4. Добавить конвертер валют (включая PRB)
  5. Собрать приложения под все платформы
  6. Провести тестирование

🔢 Основной калькулятор

  • Базовые операции: +, −, ×, ÷, %, √
  • Инженерный режим: тригонометрия, логарифмы, степени
  • История вычислений с возможностью копирования
  • Тёмная/светлая тема, адаптация под экран

👉 Справа — работающее демо приложения

🧮 Решение уравнений

  • Линейные: 2x + 5 = 13
  • Квадратные: x² − 4x + 3 = 0
  • Пошаговое объяснение решения
  • Проверка дискриминанта и корней

Полезно для самопроверки домашних заданий

🔢 Конвертер систем счисления

  • Двоичная (BIN): 101010
  • Восьмеричная (OCT): 52
  • Десятичная (DEC): 42
  • Шестнадцатеричная (HEX): 2A
  • Мгновенная конвертация между всеми системами

Полезно для уроков информатики и программирования

🔄 Конвертер величин

  • Длина, вес, площадь, температура, время
  • Валюты: USD, EUR, MDL, PRB (рубль ПМР)
  • Обновление курсов через интернет
  • Работа офлайн с последними известными курсами

Единственное приложение с поддержкой местной валюты
